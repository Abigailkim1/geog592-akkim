# Week 12 — Data Quality and Reproducible Workflows

## Module 11 – Data Validation and Cleaning

Collaborating with multiple people on the same file. 
Main folder in GitHub is repository, we bring to our computer by *cloning*. 
*Commit* saves a moment of changes to a repo with a name. 
To make changes to your repo in the cloud, you must *push* the files. 

*Fetch*: Check how the files in the cloud compare to the files on your computer.
*Pull*: Bring what is in the repo to your local folder. 

When you have many people working on a project, don't want to make direct changes to the main folder. 
So you create *branches*, so each person can work on a different branch. 
The different branches can be brought together and *merged*.
